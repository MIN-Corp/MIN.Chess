## Feature B: Change / Remove in-game agent (opposing player only, game continues)

**Messages** (enum 22, 23): `AgentChangeRequestMessage { AgentType }`, `AgentRemoveRequestMessage` (empty).

**`AgentService.cs`** — two handlers:
- `HandleAgentChange(message, type)`: sender must be a player; opponent seat must be AI → new `ChessPlayer` + swap `agents`/`agentPlayers` entries → `roomService.ReplacePlayer(...)`. No restart, no `OnPlayerLeft` — game continues.
- `HandleAgentRemove(message)`: same validation → clear `agents`/`agentPlayers` entry → `roomService.RemovePlayer(...)` → fires existing `OnPlayerLeft` → game restarts, seat opens for join/spectator-takeover.
- Also add sender-is-player validation to existing `HandleAgentChoose` (currently a spectator can trigger the `Player.None` seat bug).

**`RoomService.cs`** — two helpers:
```csharp
public async Task ReplacePlayer(Player role, ChessPlayer replacement)
{
    players[role] = replacement;
    await messageService.BroadcastAsync(new PlayerConnectedMessage { Role = role, Participant = replacement });
}

public async Task RemovePlayer(Player role)
{
    players[role] = null;
    OnPlayerLeft?.Invoke(role);
    await messageService.BroadcastAsync(new PlayerDisconnectedMessage { Role = role });
}
```

`HandleMove` calls it when opponent is AI (removes the duplicated loop). New public handler:
```csharp
public async Task HandleStartGame(INetworkMessage message)
{
    var senderId = Guid.Parse(message.SenderId);
    var seats = roomService.GetPlayers();

    if (seats[Player.White]?.IsAi != true || seats[Player.Black]?.IsAi != true)
    {
        await messageService.SendErrorAsync(senderId, "Для запуска нужны два агента");
        return;
    }

    if (!GameState.IsGameOver() && lastMove != null)
    {
        return; // игра уже идёт
    }

    if (GameState.IsGameOver())
    {
        Restart();
        await ManageStartGameStateOutOfPlayerPresence();
    }

    await PlayAiMovesFromCurrentPosition();
}
```
Any human (spectator included) may press start/restart — this covers AI-vs-AI restart since spectators can't vote.
